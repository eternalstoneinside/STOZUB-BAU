# STOZUB BAU

A German-language business website presenting construction and renovation services in Austria.

[Live demo](https://eternalstoneinside.github.io/STOZUB-BAU/)

## Overview

STOZUB BAU is a responsive company presentation focused on clear service positioning, credibility, project assurance, and direct contact routes.

## Highlights

- German-language content
- Responsive business landing page
- Company, services, advantages, and assurance sections
- Search and social metadata
- Direct contact calls to action
- Optimized decorative and branded assets

## Tech stack

HTML5 · CSS3 · JavaScript

## Run locally

```bash
git clone https://github.com/eternalstoneinside/STOZUB-BAU.git
cd STOZUB-BAU
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Project structure

```text
index.html       Page content
css/main.css     Responsive styling
js/main.js       Navigation and interactions
img/             Branding and section artwork
```
